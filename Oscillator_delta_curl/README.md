## Common harmonic calculation

For these five analysis scripts, delta is calculated from corresponding waveform and PPV harmonic amplitudes and phases:

```text
denominator = sum_n n*alpha_n*beta_n
delta_n = abs(n*alpha_n*beta_n*cos(chiZ_n-chiV_n))/denominator
delta = sum_n delta_n
```

DC is excluded. The scripts display the first ten harmonics, while the total delta uses the separately configured `n_harmonics2` range. Delta is the harmonic-misalignment measure plotted in the paper; these scripts do not calculate a two-dimensional RMS curl.

The adjoint scaling targets `z^T*f=1` (scalar `z*f=1` for the PWL model). A constant conversion to angular-phase normalization changes PPV magnitudes but cancels from delta.

The current `n_harmonics2=8000`, `M_fft=8192` settings index beyond the unique positive-frequency FFT range. Bins above 4096 represent negative frequencies but are weighted as positive orders in this implementation. Preserve this setting only when reproducing the existing calculation; new quantitative validation requires correcting the harmonic range or increasing FFT resolution and checking convergence.

## Running the paper-plot scripts

Open the desired script by its full path, edit its parameter block if needed, then run it in MATLAB. For example:

```matlab
run('D:\Abir\Hopf\New folder (2)\Plots\New folder\Fourier_analysis_PPV_VDP_Full_DeviationGD_Deltavsmu.m');
```

The scripts use MATLAB functions including `findpeaks`, `ode45`/`ode15s`, `interp1`, `fft`, and `exportgraphics`. They start with `clear; clc; close all;`, so settings must be changed inside the script rather than supplied as workspace overrides.

Each script uses its own absolute `PLOT_DIR`. Running it again overwrites matching output files. The two VO2 versions share output filenames, so preserve existing files or change `PLOT_DIR` before comparing versions. A script may also generate diagnostic figures beyond the particular plot used in the paper.

The mapping above is based on source inspection and comparison with the paper's saved plot assets. Creating this README did not rerun MATLAB or regenerate the paper plots.
